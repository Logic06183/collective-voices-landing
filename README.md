# collective-voices-landing

Landing page for Collective Voices for Health Access, a coalition of civil society organisations, activists, healthcare workers and researchers campaigning for the right to health for all in South Africa.

Live at https://logic06183.github.io/collective-voices-landing/

A single self-contained `index.html`: inline CSS, one base64-embedded logo, Google Fonts, no JavaScript, no build step and no dependencies.

## Editing and previewing

Content and styles both live in `index.html`. Open the file directly in a browser to preview — there is nothing to install or serve. Keep it to one file so the page stays trivial to host and review.

## Deployment

GitHub Pages serves the repository root from `main`, so a push to `main` publishes.
