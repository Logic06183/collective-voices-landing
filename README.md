# collective-voices-landing

Landing page for Collective Voices for Health Access.

A single self-contained `index.html` with inline CSS, no build step and no dependencies. Open the file in a browser to preview, and deploy by serving it as a static page.

## Editing

Content and styles both live in `index.html`. Keep it to one file so the page stays trivial to host and review.
